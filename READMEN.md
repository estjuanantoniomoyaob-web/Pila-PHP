# Estructura de Datos: Pila (Stack) de Estudiantes en PHP Nativo

Este proyecto implementa la estructura de datos **Pila (Stack)** utilizando arreglos nativos de **PHP** y sesiones de usuario (`$_SESSION`), con una interfaz web interactiva en HTML.

## Cómo ejecutar el proyecto PHP (CMD / Terminal)

1. Abre la consola en la raíz de la carpeta del proyecto.

2. Ejecuta el servidor web integrado de PHP (usando XAMPP):

```cmd
C:\xampp\php\php.exe -S localhost:8000
```

3. Ingresar al navegador 
```cmd
http://localhost:8000/
```
